# Oluwatosin Ogunsina Portfolio

A responsive, single-page portfolio built with HTML, CSS, and JavaScript. It is designed as a fresh recreation inspired by the publicly visible structure and plum/cyan palette of the existing portfolio.

## Files
- `index.html` — page content and Netlify contact form markup
- `style.css` — responsive styling
- `script.js` — mobile menu, FAQ markers, back-to-top button, and current year
- `assets/` — place your own licensed images here

## Before publishing
1. Replace the two portrait placeholders with your professional photo. The placeholders are intentional; no original image was available in the live-site inspection.
2. Review every service and statement to make sure it accurately reflects your experience and offer. Remove anything you do not provide.
3. Add your email and professional social profile links where desired.
4. The contact form uses Netlify Forms markup. Deploy the site to Netlify, submit a test message, then enable form submission notifications in the Netlify dashboard. A form does not automatically email you unless notifications are configured.
5. Do not add invented testimonials, client names, metrics, or results. Add only genuine, permission-approved proof.

## Test locally
Open `index.html` in a browser. For best testing, use a simple local server or your code editor's preview feature.

## Deploy with GitHub + Netlify
1. Create a GitHub repository and upload these files.
2. In Netlify choose **Add new project** → **Import an existing project** → **GitHub**, then select the repository.
3. For this plain HTML project, no build command is needed and the publish directory is the repository root (`.`).
4. Deploy. Netlify will provide a `netlify.app` address.
5. In Netlify's Forms/Notifications settings, configure email notifications and test the contact form.

## Important
This is a recreated implementation, not a copy of the original developer's source code. It uses a new structure and generic service copy based on the publicly visible portfolio positioning. Review all content before publishing.
